# Авито: машины до миллиона

Подборка легковых машин с Авито: с пробегом, автомат/вариатор/робот, до 1 000 000 ₽, до 200 л.с.,
до 3 владельцев по ПТС, не битые, только частники, цена по оценке Авито «хорошая» или «отличная».
Регионы: Ростовская область (далее — Краснодарский край, Москва, Московская область).

Дашборд: `index.html` (открывается через GitHub Pages).
Сборка: `python3 собрать_дашборд.py` (берёт данные из папки `данные/`, которая в репозиторий не попадает).
